# ローカル専用動作: ui計画

本書は2026-09-08の実装指示に基づく契約。

## 担保 AC（引用文）

- **AC-7**: クリーンなブラウザと外部通信遮断環境で、主要画面・CRUD・検索・Inbox・Manual Runが動作し、アプリと起動ツールから外部通信を試みない。

## 公開する契約案

画面パス、業務API、Request / Responseの変更はない。既存の`src/lib/api-client.ts`による同一Originへの相対URL通信を使用する。

## UI/UX 方針

- `src/styles.css`のGoogle Fonts importを除去し、本文・見出しを`ui-sans-serif, system-ui, sans-serif`へ統一する。フォントのダウンロード・外部CDNを追加しない。
- Home、Issue一覧・詳細、Project、Cycle、View、Search、Inbox、Settingsの既存導線を維持する。
- 初期化後はデモIssueの代わりに既存の空状態を表示する。空データでもIssue / Projectを作成できることを確認する。
- 初期・ローディング・入力・保存成功・APIエラーの既存表示を再利用する。DB保存失敗を成功表示にしない。
- 実装調査でAccessログアウトや認証URLへの導線が見つかった場合、localでクラウドURLへ遷移しないよう扱いを決め、必要なUI契約を実装前に追記する。
- Manual Runは既存の進捗・ロック・再開表示を使用する。サーバー停止中に処理が進むとの表示を追加しない。

## レスポンシブ / アクセシビリティ

既存レイアウトとブレークポイントを維持し、390px / 768px / 1280pxでフォント変更による切れ・折返し・横スクロールを点検する。スマホ・タブレット幅は同一PCのviewportで確認し、LAN経由の実機対応は含めない。既存キーボード操作、フォーカス表示、ラベル、コントラストを維持する。

## 実装配置

`src/styles.css`が主対象。`src/components/OrbitApp.tsx`、`src/lib/api-client.ts`、`src/routes/`は既存動作の確認対象とし、必要のない書き換えを行わない。

## 異常系挙動

400 / 409 / 500 / 423は既存APIエラー表示と再試行・Run表示を使用する。localで認証失敗をAccessへ自動転送する経路がないことを確認する。停止したローカルサーバーへ接続できない状態を、クラウド認証失効として扱わない。

## テストケース

- [代表値] 外部フォントを含まないCSSで日本語・英語の本文と見出しを表示する。
- [状態遷移] 空状態→Issue / Project作成→更新→再読込→削除・復元を外部通信なしで確認する。
- [代表値] View保存、検索、Inbox既読化、Settings変更、Manual Run開始・完了を確認する。
- [同値分割] 保存成功 / DBエラー / 競合 / Run中の状態を既存UIテストで確認する。
- [代表値] キャッシュ・Service Workerなしのブラウザで、全主要画面の自動通信がloopback内だけであることを検証する。CSSの静的検査だけで合格にしない。
