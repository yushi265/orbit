## 振り返り（KPT）

> Gate 3 で蒸留する。このノートの主役。

### Keep（効いた・次も続ける）
- 前ボルトの Try を委譲文に入れたことで、整形ノイズと理由の記録漏れがゼロになった
- レビュー指摘を RED / ミューテーションで裏取りしてから直した

### Problem（詰まった・摩擦・想定外）

> 各項目の先頭に分類タグ `[カテゴリ]` を付ける（棚卸しでの再発チェック集計キー）。
> カテゴリ: `spec` / `tdd` / `review` / `gate` / `boundary` / `security` / `tooling` / `other`。

- `[tdd]` CSS の追加ルールが、前にあるモバイル用メディアクエリを後勝ちで上書きする回帰を、既存テストが検出できなかった
- `[tdd]` 「見つからなければ何もしない」形のテストが空通過していた（`if (x) ...` の後に for で検証）

### Try（次ボルト以降でフローをこう変える）
- CSS をファイル末尾に足すときは、同じセレクタがモバイルのメディアクエリにないかを確認する（codekb の罠に追記ずみ）
- テストの前提条件（要素が見つかること）は `if` で飛ばさず expect で固定する
