## メタ

- ticket: FEAT-review-followup
- 機能概要: ローカル画面確認で追加された操作と表示の改善。
- Stage: Tier1、要件/spec/TDD/品質ゲート/3観点レビュー/コミットを実行。
- トークン実測: 未計測。
- 着手日: 2026-10-02
- 完了日: 2026-10-03

## 各Stageの気づき

| Stage | 気づき |
|---|---|
| 調査・契約 | HomeのOpenと7日以内は既存一覧の完了非表示/upcomingと範囲が異なる。遷移先にも同じ条件を表す。 |
| UI調査 | SSR loading→データ表示とページ登場animation、StrictModeのrenderを分けて確認する。 |
| 保存 | 属性の即時保存は説明flushと直列化する。flushが待つsaving flagを先に立てると自己待ちになる。 |
| レビュー | latestRun表示のhelperだけではcontrollerの30秒poll後の状態を保証しない。境界NoopとDnDの個別passも、後続操作への残存intentを保証しない。 |

## KPT

### Keep

- カード集計とリンク先Filterを同じ境界で検証する。
- 保存失敗、409、説明保存中、連打を実DOM操作で確認する。

### Problem

- [spec] 同じ「未完了」「近日」でも画面ごとの対象が異なり、クリック先と件数がずれる。
- [review] 初回表示・個別操作のテストが通っても、既存pollや後続操作と組み合わせた状態遷移の不整合が残った。

### Try

- 集計カードの受け入れ基準に、遷移先の対象集合との一致を含める。
- 既存controllerへ新しい表示をつなぐ場合、定期再取得後と境界操作後の次操作まで検証する。

## フロー改善候補

| Try | 還流先 | 状態 |
|---|---|---|
| 集計カードと一覧条件の一致 | UI spec / テスト戦略 | 提案のみ。共有ハーネス変更は対象外 |
| 定期取得後・境界操作後の複合状態 | UI/Controllerテスト戦略 | 当該回帰は反映済み。共有ハーネスへの昇格は提案のみ |
