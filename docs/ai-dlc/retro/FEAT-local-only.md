## 振り返り（KPT）

### Keep

- 環境設定表を先に固定し、Memory / local D1 / productionを同時に回帰検証した。
- 独立レビューでコピー先とlock領域の重複による成果物消失を発見し、RED再現から修正した。

### Problem

- [tdd] 手書きSQLの実D1テストだけでは、本物RepositoryのCAS条件の回帰を検出できなかった。公開Repositoryを呼ぶ実D1テストへ置換した。
- [boundary] コピー本体の親子関係だけでなく、後始末するlock領域もデータ安全性の対象だった。
- [tooling] OSの外向き遮断は検証できたが、全native通信試行ログは陽性対照が成立せず未確認。通信非依存と試行ゼロ監査を分けて報告した。

### Try

- 永続化の結合テストは本物Repositoryから通すことをcodekbへ記録（反映済み）。
- ファイルコピーの排他領域も重複検査へ含める罠をcodekbへ記録（反映済み）。
- 通信監査が要件にある場合は設計段階で陽性対照の成立を先に確認する（未採用の学び候補）。
